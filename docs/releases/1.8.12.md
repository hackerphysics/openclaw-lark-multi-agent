# 1.8.12 — strict current-activity proof across pending pages

Includes the retained-input and input-projection fixes from 1.8.11, with the
additional release-review correction: every non-runnable pending page and the
final head recheck must explicitly confirm `hasActiveRun:false`. Missing/null/
string/numeric activity flags stay unknown instead of becoming idle because a
valid tail page matched. The head recheck must remain within the absolute scan
budget. Positive queued/active/in-flight work remains busy.

Independent head/deadline, actual Bot admission, middle-page and private-output
controls are permanent formal regressions. Work remains attributed to the exact
session, owner/batch and stop generation. No Gateway pending records are deleted
or replayed; only proven never-attempted local inputs may resume normal admission.

The internal forwarded-input guard still uses structured provenance and input
identity rather than deleting message prefixes or blocking genuine assistant
quotations, Cron output or child continuation results. No plugin change: lma-core
remains 0.2.0.

This release is a new immutable version, not an overwrite of the already-created
1.8.11 tag. Source verification, publication, runtime activation and real message
acceptance are separate receipts.
